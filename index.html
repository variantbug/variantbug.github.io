When a vendor fixes one bug, the same root cause often survives elsewhere. We diff the patch, re-derive the flaw class, and hunt its siblings — in the same project, its forks, and downstream vendors.

Research focus

  • 01
    Patch-diff → variant

    Upstream fixes as a map to unpatched code paths — same project, forks, downstream vendors.

  • 02
    Chain assembly

    One finding is priced by what it reaches. We test whether it lowers the barrier for another before reporting either.

  • 03
    Verified only

    Every report ships with a reproduction. No repro, no report.
